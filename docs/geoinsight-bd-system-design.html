Functional Requirements

২.১ · Auth & Authorization

Identity ও Access

  • Email/password login
  • JWT access (১৫ মিনিট) + refresh (৭ দিন), rotation সহ
  • Role-based access: PMO, MINISTER, DC, UNION_CHAIRMAN
  • প্রতিটি role নির্দিষ্ট admin_unit_id scope-এ সীমাবদ্ধ
  • Session revoke / JWT denylist
  • Registration শুধু PMO করতে পারে
২.২ · Admin Hierarchy

Hierarchy Management

  • DIVISION → DISTRICT → UPAZILA → UNION
  • GeoJSON boundary সহ admin unit management
  • Denormalized division/district/upazila_id দিয়ে hierarchy filtering
২.৩ · Representative & KPI

KPI Lifecycle

  • Representative CRUD (MP, Minister, DC, Union Chairman)
  • KPI status flow: DRAFT → SUBMITTED → VERIFIED → REJECTED
  • Representative / project / admin unit / national level KPI
  • Optional Hyperledger blockchain hash anchoring
২.৪ · Project & Red Flags

Project Tracking

  • Budget, status, contractor tracking
  • AI red-flag: overrun, delay, corruption risk, quality, fraud
  • Alert resolve workflow + audit trail
২.৫ · Dashboard & Real-time

Live Intelligence

  • Choropleth map (Bangladesh districts/divisions)
  • KPI scorecards, budget variance, completion charts
  • Socket.io live update: kpi:update, alert:created
  • Role-scoped hierarchical rooms
২.৬ · Agro-Economic Intel

Market Intelligence

  • Agro market (wholesale, retail, haat, mandi) mapping
  • Global commodity price time-series (TimescaleDB)
  • Arbitrage heatmap — landed cost comparison
  • Background scraper — ৫ মিনিট interval
২.৮ · Public Feeds

Unauthenticated Access

  • National helpline 333 ও emergency 999 feed stream
  • Sovereign IP guard + strict rate limiting
  • Bangla sentiment overlay
২.৯ · Blockchain

Immutable Anchoring

  • Hyperledger Fabric milestone anchoring
  • Retry queue + dead-letter handling
  • Default: FABRIC_ENABLED=false
২.১০ · Audit & Search

Traceability

  • Critical action audit log (user, IP, old/new value)
  • Cross-module search
২.১১ · Document Storage

Object Storage

  • MinIO-তে national intelligence documents
  • Bucket: national-intelligence-docs

৫.৪ Auth Flow

Login — POST /api/auth/login (Next.js) → POST /api/v1/auth/login (Gateway) → bcrypt verify → issue accessToken + refreshToken → set HTTP-only cookies gi_access_token, gi_refresh_token
Authenticated call — GET /api/proxy/kpis/definitions (Next.js) → read cookie → Authorization: Bearer <token> → Gateway authenticate() → rbac.authorize() → Prisma query
Token refresh — POST /api/auth/refresh → hash verify refresh_tokens table → rotate → new cookies
Logout / Revoke — JWT jti → Redis denylist; refresh_tokens.revoked_at = now()

BFF routes: web/dashboard-nextjs/src/app/api/auth/, web/dashboard-nextjs/src/app/api/proxy/

৫.৫ RBAC Scope Logic

rbac.authorize()
PMO            → admin_unit_id = NULL → সব unit access
MINISTER       → DIVISION level unit
DC             → DISTRICT level unit
UNION_CHAIRMAN → UNION level unit

authorize(targetAdminUnitId):
  userScopeChain = Redis cache (admin hierarchy)
  target must be descendant of user's unit

Schema: services/api-gateway-node/prisma/schema.prisma — UserRole, RolePermission

৭.৩ Redis — ৫টি Use Case

1JWT Denylist

Problem

Stateless JWT logout করলেও token valid থাকে

Solution

revoked jti → Redis TTL = token expiry

2Rate Limiting

Problem

Public 333/999 feeds DDoS target

Solution

rate-limit-redis → per-IP sliding window

3Admin Hierarchy Cache

Problem

RBAC scope check = recursive tree walk

Solution

Admin unit chain cached, O(1) lookup

4Socket.io Adapter

Problem

Multiple gateway instances = rooms split

Solution

Redis pub/sub → all instances same rooms

5Arbitrage Cache

Problem

Global price scrape expensive (৫min cycle)

Solution

TTL cache (3600s) → fast heatmap response

Key files: jwt-session.service.ts, rate-limiter.middleware.ts, admin-scope.service.ts, socket.server.ts

৭.৪ RabbitMQ — কেন?

1Async AI Jobs

Problem

Sentiment / arbitrage / risk = seconds-long

Solution

Queue → AI worker background-এ process করে

2Service Decoupling

Problem

Gateway সরাসরি AI call = tight coupling

Solution

Topic exchange → routing by event type

3Real-time Fan-out

Problem

KPI update → many dashboard clients

Solution

gov_core_queue → Socket.io broadcast

4Durability & Retry

Problem

AI service down = lost jobs

Solution

Durable queues, message persistence

5Load Leveling

Problem

Spike in sentiment batches

Solution

Queue buffers → worker pool (size: 4)

Redis
fast cache + pub/sub
vs
RabbitMQ
reliable delivery + durability

ephemeral speed vs durable routing — আলাদা দায়িত্ব
