১. Project context ও goal

কেন এই সিস্টেম?

একটা সার্ভিস সিলেক্ট করুন

কেন ৩টা আলাদা app service?

Next.js Dashboard

UI, maps, charts, BFF cookie auth। Browser-এ token যায় না — XSS surface ছোট।

Node API Gateway

একটা REST entry, RBAC, Prisma, Socket.io, Fabric, MQ consumer। Gov business logic এখানে।

Python AI Analytics

PyTorch, OpenCV, Shapely, Ollama — GPU/CPU ML আলাদা scale হয়, Node-কে block করে না।

৪টা communication pattern

1. Sync HTTP→Dashboard BFF→Gateway→AI FastAPI
2. Async MQ→geoinsight_exchange→gov.* / ai.* queues
3. Realtime→Rabbit consumer→Socket.io rooms→unit / division / national
4. BFF auth→HTTP-only cookies→same-origin proxy /api/proxy/*
Redis = cache, rate-limit, JWT denylist, Socket adapter (গতি)। RabbitMQ = durable jobs ও fan-out (নির্ভরযোগ্যতা)। দুটো এক জিনিস নয়।

৬. Low Level Design (LLD)

৬.১ Auth flow

  1. POST /api/auth/login (Next) → Gateway bcrypt verify। MFA থাকলে mfaToken challenge।
  2. Success-এ gi_access_token + gi_refresh_token HTTP-only cookies।
  3. API: /api/proxy/kpis/... cookie → Authorization: Bearer → authenticate() + rbac.authorize()।
  4. 401 হলে silent /api/auth/refresh, একবার retry; 403 → /forbidden।
  5. Logout: refresh revoke + Redis jti denylist।

৬.২ RBAC scope

PMO-এর admin_unit_id = NULL = সব unit। অন্যরা নিজ unit-এর descendant দেখে। Hierarchy chain Redis-এ cache হয় যাতে প্রতি request-এ tree walk না হয়। MP/Mayor আলাদা Local DSS surface পায় (CONSTITUENCY / CITY_CORPORATION)।

৬.৩ Gateway modules

Register: services/api-gateway-node/src/modules/register-modules.ts — auth, admin-unit, kpi, project, alert, dashboard, briefing, intelligence, ingestion, pipeline, weather, unrest, narrative-shield, outlook, divisional-crisis, local-entity, simulator, procurement, sovereign, twin, audit, citizen, search, public-feed, blockchain.

৬.৪ AI routers

FastAPI /api/v1: sentiment, briefing, outlook, weather, ingestion, sovereign-llm, predictive, arbitrage, procurement, phishing, proximity, face-intel, narrative-shield, documents, hazards, twin, simulator, citizen, local_ai.

৬.৫ Read/write split

DATABASE_URL → PgBouncer write → primary। DATABASE_READ_URL → read pool / replica। Migrations শুধু DIRECT_DATABASE_URL।

৬.৬ Real-time pipeline

KPI/alert DB write → publish gov.kpi.update → gov_core_queue → broadcastToHierarchy(adminUnitId) → rooms unit:{id}, division:{id}, national → dashboard hooks refetch.

৮. Tech stack — কোনটা কেন, কী করে, কেন best

Filter চাপুন। প্রতিটা কার্ডে: কাজ, এই প্রজেক্টে ব্যবহার, বিকল্প কেন নয়।

৯. Security architecture

Edge → App → Data

nginx TLS/CSP/rate-limit → Next BFF → JWT 15m + refresh → RBAC + admin-unit scope → audit log। Passwords bcrypt 12। MinIO private bucket। Ollama শুধু app VPS থেকে :11434।

Threats যেগুলো আটকানো হয়েছে

XSS token theft (HTTP-only), CSRF same-origin BFF, privilege climb (descendant check), public feed flood (Redis limiter), lookalike gov sites (phishing DSS), session steal after logout (denylist).

১১. Behind the scene — technology কীভাবে কাজ করে

কয়েকটা end-to-end chain — PMO desk থেকে DB/AI পর্যন্ত।

A. খবর → Unrest → Outlook → Morning Brief

  1. Pipeline/ingestion worker AI /ingestion/fetch চালায় (RSS + Google News)।
  2. Geo-match + Bangla-BERT sentiment → Gateway upsert ExternalArticle।
  3. Unrest module keyword/cluster করে district score → snapshot UNREST (Redis cache)।
  4. Outlook AI (Ollama structured JSON) themes + unrest নিয়ে snapshot OUTLOOK।
  5. Briefing copilot KPI/alerts + intel snapshots থেকে bn/en bullets + TTS।

B. Local complaint SLA

  1. MP/Mayor UI থেকে complaint create (ward, GPS, before-photo, red-alert)।
  2. Optional /complaints/triage → local_ai fast model category/severity suggest করে।
  3. Assign / start / notes timeline Prisma-এ। SLA hours পার হলে OVERDUE।
  4. Resolve-এ after-photo বাধ্যতামূলক — evidence trail। Alert delivery SMS/voice test করা যায়।
  5. WPI recompute ward scores (complaints + outages + specialty signals) → heatmap/scorecard।

C. Anti-phishing RED_FLAG

  1. Analyst URL paste → Gateway /intelligence/phishing/scan → AI HTML fetch।
  2. DOM skeleton + meta + visual tokens → SHA-256 signature।
  3. Official .gov.bd gallery-র সাথে TF-IDF cosine + Levenshtein।
  4. Score ≥ threshold এবং domain allow-list-এ না → RED_FLAG।

D. Face Intel ethical card

  1. Webcam/upload → OpenCV Haar + embedding gallery match (dlib নয়, Docker-friendly)।
  2. Gateway Prisma ৬ মাস: red flags, budget overrun, grievance KPI, news proxies।
  3. UI ethical_score 0–100 + allegations — CV Python-এ, aggregation Node-এ (RBAC থাকে)।
