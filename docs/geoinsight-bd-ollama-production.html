AI Infrastructure Guide

Ollama in Production

GeoInsight BD-এর জন্য sovereign LLM কীভাবে আলাদা AI server-এ চালানো হয়, app VPS-কে হালকা রেখে।

Setup, firewall rules, local dev fallback, GPU acceleration, আর Ollama down হলে কী হয় — সব এক জায়গায়।

Model · llama3.1:8b Port · :11434 Placement · Separate AI server RAM · ≥16GB recommended
!

Do not run Ollama on the same small Hostinger app VPS — এতে swap হবে আর পুরো সাইট slow হয়ে যাবে।

AI Server Setup

AI machine-এ repo clone বা copy করার পর setup script চালান — এটা docker-compose.ollama.yml স্টার্ট করে, llama3.1:8b pull করে, আর UFW থাকলে শুধু app VPS-কে allow করে।

AI machine
# clone or copy repo onto the AI machine
cd /opt/geoinsight-bd
bash deploy/scripts/ollama-server-setup.sh --allow-from <APP_VPS_PUBLIC_IP>

Check

verify
curl -s http://127.0.0.1:11434/api/tags
docker exec geoinsight-ollama ollama list
০২

Point the App VPS at Remote Ollama

App VPS-এ:

app VPS
cd /opt/geoinsight-bd
bash deploy/scripts/vps-point-ollama.sh http://<AI_SERVER_IP>:11434

এটা .env আপডেট করে:

.env
LLM_PROVIDER=ollama
OLLAMA_URL=http://<AI_SERVER_IP>:11434
OLLAMA_MODEL=llama3.1:8b
SENTIMENT_USE_MOCK=true

… আর geoinsight-ai-analytics recreate করে।

Verify

verify
curl -s http://127.0.0.1:8000/api/v1/sovereign-llm/status
# or via gateway after login — ollama_reachable should be true

Local Windows (Dev)

Host Ollama ব্যবহার চালিয়ে যান:

.env · local dev
OLLAMA_URL=http://host.docker.internal:11434

ollama serve / Docker Desktop already running হলেই যথেষ্ট।

GPU (Optional)

docker-compose.ollama.yml-এ NVIDIA deploy.resources ব্লক uncomment করুন, আর nvidia-container-toolkit ইনস্টল করুন।

০৬

Fallback Behaviour

Ollama down হলে Sovereign LLM template replies-এ fallback করে (sovereign_template)। Dashboard-এর বাকি অংশ কাজ করতে থাকে।

StateBehaviour
Ollama reachableFull LLM responses — sovereign, on-prem
Ollama unreachableFalls back to sovereign_template mode — dashboard stays up
